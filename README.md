# WinTuneBox · Windows 优化工具箱

**一个免费的 Windows 优化工具箱，由上一版 WinOptimizer 重构而来。**

不用装全家桶、不用看广告、不会偷偷联网。想清理垃圾、关掉没用的开机启动、让电脑快一点，
在这里点几下就行 —— 而且**每一步改了什么都能看见，改坏了都能退回去**。

| | |
|---|---|
| 💰 **完全免费** | 开源，MIT 协议，无付费功能 |
| 🚫 **干净** | 无广告、无捆绑、不装后台服务、不常驻驱动 |
| 🔌 **不联网** | 不联网、不收集数据、不检查更新 |
| ↩️ **可撤销** | 改动前自动备份，单项能还原，整体能回滚 |
| 🪶 **轻量** | 平时只占 **8.7 MB** 内存，启动 **0.8 秒** |

支持 **Windows 10 / Windows 11**（64 位和 32 位系统都有）。

## 🎯 它能帮你做什么

按你最可能遇到的情况说：

**电脑用久了变卡、开机变慢**
→ 「一键优化」里挑一个场景（推荐先用**安全推荐**），点应用。会关掉一些没用的后台负担、优化系统响应。
→ 「启动项管理」看看有哪些程序开机就自动跑，用不上的关掉。

**C 盘红了、空间不够**
→ 「垃圾清理」清临时文件、缓存、日志、系统升级残留。
→ 「存储分析」看清楚到底哪些文件夹和文件占了地方（**只查看、不删除**），心里有数再自己处理。

**想卸载软件**
→ 「软件管理」列出已装的程序，一键跳到卸载。

**网络不顺、想换 DNS**
→ 「网络工具」快速切换常用 DNS、编辑 hosts、重置网络。

**担心隐私被收集**
→ 「一键优化」的隐私分组里，可以关掉定位、活动历史、输入习惯上传、各种诊断数据上报等。

**想知道自己电脑安全不安全**
→ 「安全体检」给一份体检报告（杀毒防护、防火墙、系统更新等是否正常）。
**这一页只看不改**，不会动你的任何安全设置。

**不小心改坏了想恢复**
→ 「备份还原中心」，恢复到你之前存的快照。

**其他小工具**
→ 「更多工具」里有电源方案切换、内存整理、系统工具快捷入口、安全模式开关等。

## 🚀 第一次打开

双击 `WinTuneBox.exe` 就能用。**它不会一上来就乱改东西** —— 打开后只是先把你电脑现在的状态读一遍，
告诉你哪些地方可以优化，改不改、改哪几项都由你自己决定。

第一次打开，建议按这个顺序来：

1. **看一眼左下角的权限条。** 改系统服务、清组件存储、建还原点这几类操作必须有管理员权限。
   如果显示的是普通权限，点一下它就能以管理员身份重启；只是清理和查看的话，不提权也够用。
2. **先建一个还原点。** 打开「备份还原中心 → 创建快照」，几秒钟存下当前状态。
   之后不管动了什么，都能一键回到这里，这是最省心的保险。
3. **再去「一键优化」挑一个场景**（不确定就选「安全推荐」），把想改的勾上，点应用。

第一次运行会在 `%LOCALAPPDATA%\WinTuneBox` 建一个文件夹，用来存设置和备份记录（详见「卸载 / 我的数据在哪」）。

> 每项优化旁边都有 **已优化 / 待优化** 的标记，这是程序实时检测出来的结果，不是猜的 ——
> 所以你已经手动改过的项目，它不会再多动一遍。

## 🛡 它安全吗

这是最该问的问题，所以直接说清楚。

**它不联网。** 程序里没有任何联网、上传、下载功能：不检查更新、不收集使用数据、不发统计、
不下载任何东西。你可以断网用，也可以直接用防火墙拦着它，功能不会少。

**改之前一定先备份。** 每个优化项在动手之前，都会把原来的值记下来存到
`%LOCALAPPDATA%\WinTuneBox\backups\`，所以：

- 单项可以**随时还原**（页面上的「还原」按钮）
- 整体可以**回到之前的快照**（备份还原中心）

**它明确不碰这些东西：**

- ❌ 不碰杀毒软件和 Windows Defender
- ❌ 不改 Windows 更新的策略
- ❌ 不关闭系统还原功能
- ❌ 不删除你的个人文件
- ❌ 不安装驱动、不装后台服务、不进系统内核

**危险的操作会反复提醒。** 标了「谨慎」的项目默认**不勾选**，得你自己去点；
完全不可撤销的操作（比如组件存储清理的 `/ResetBase`、清空回收站、删除还原点）
会单独再弹一次确认框，写清楚后果才让你继续。

**管理员权限只在需要时要。** 改系统服务、清组件存储这类操作才需要提权，
其余时候程序用普通权限运行，不会一直在后台挂着高权限进程。

**卸载后不留东西。** 不装服务、不装驱动、不写开机自启（除非你自己在设置里打开），
只会在 `%LOCALAPPDATA%\WinTuneBox` 留一个数据文件夹，卸载程序不会去动它（要不要删由你决定）。

## ❓ 常见问题

**Q：杀毒软件报毒 / 提示有风险，怎么办？**

大概率是**误报**，原因跟"有没有签名"没什么关系，而是这类工具天生带着一些**高危动作**：
清理系统事件日志、删除系统还原点、夺取文件所有权后强制删除……这些动作本身也是木马会做的，
所以杀软的"行为特征"容易命中。

这个程序不联网、不下载、不上传任何东西，你可以自己核对（源码全公开）。

处理办法：

1. 确认文件是从本项目的**发行页面**下载的（不要用来路不明的转载版本）；
2. 用发行页面里的 `SHA256SUMS.txt` 核对一下文件的 SHA-256；
3. 确认没问题后，在杀软里把它加进**信任 / 白名单**，或者临时关掉实时防护再安装；
4. 也可以向杀软厂商**提交误报申诉**（火绒 / 360 / 腾讯管家的反馈入口，或者微软的
   [文件提交页](https://www.microsoft.com/wdsi/filesubmission)）。

**Q：安装时提示「Windows 已保护你的电脑」或者「未知发布者」？**

因为本项目用的是**自签名证书**（免费签名证书的固有限制，没法像商业软件那样免提示）。
想让它显示成"已验证的发布者"，需要手动信任一次随包提供的根证书：

- 双击 `WinTuneBox-RootCA.cer` → 「安装证书」→ 存储位置选「**本地计算机**」→
  选「**将所有的证书都放入下列存储**」→ 选「**受信任的根证书颁发机构**」→ 完成

不装也没关系，点「更多信息 → 仍要运行」一样能用，只是每次会提示一下。

**Q：我点了优化，怎么感觉没变快？**

优化能解决的只是"系统里没必要的负担"，如果电脑本身配置偏低、硬盘是机械盘、或者后台有
大型程序在跑，那真正卡的原因不在这一层。另外，很多改动（比如内存压缩、GPU 计划、
页面文件）**需要重启之后才生效** —— 页面上有提示需要重启的项目，重启一下再感受。

**Q：怎么彻底退出程序？**

窗口右上角的 ✕ 只是收进托盘。要彻底退出，去**右下角托盘图标上右键 → 退出**。
如果托盘图标找不到（被收进了隐藏区域），点托盘左边的小箭头 `∧` 就能看到它。

**Q：它会不会把我系统搞坏？**

绝大多数项目都是可以撤销的（改前存原值，随时还原）；少数不可撤销的操作会单独弹确认框。
但**任何系统优化工具都不可能是零风险的**，所以强烈建议：先建一个快照，再去动手。
详细的责任说明见前面的「免责声明」。

**Q：需要联网吗？会自动更新吗？**

不需要联网，也没有自动更新。想升级请到发行页面下载新版本，直接覆盖即可
（设置和数据都在 `%LOCALAPPDATA%` 下，不会丢）。

**Q：支持 Windows 7 / 8 吗？**

不支持。本版本要求 **Windows 10 1607 及以上或 Windows 11**。
如果是老系统，请用仓库里冻结的旧版 **WinOptimizer v1.0.15**。

**Q：有些按钮是灰的 / 点了提示权限不足？**

那几项需要管理员权限。点左下角的权限提示条，让程序以管理员身份重启一次即可。

**Q：卸载之后，我的设置和备份还在吗？**

在。卸载程序**不会**删除 `%LOCALAPPDATA%\WinTuneBox`，这样你重装后设置还在、备份也还在。
想彻底清干净，卸载完手动删掉这个文件夹就行。

## 📂 卸载 / 我的数据在哪

**怎么卸载？**

- 装的**安装版**：设置 → 应用 → 已安装的应用 → 找到「Windows优化工具箱」→ 卸载；
  也可以在开始菜单里找到卸载快捷方式。
- 用的**绿色版**：直接把解压出来的那个文件夹整个删掉就完事了，它没往系统里装任何东西。

**我的设置和数据在哪？**

全部集中在同一个文件夹里：

```
%LOCALAPPDATA%\WinTuneBox\
├─ settings.json    你的设置（主题、强调色、悬浮球开关等）
├─ backups\         每个优化项改动前的原始值，用于「单项还原」
├─ snapshots\       你手动创建的系统快照记录
└─ logs\            运行日志，出问题时可以拿来看
```

把 `%LOCALAPPDATA%\WinTuneBox` 直接粘到文件资源管理器的地址栏回车，就能打开这个文件夹。

**注意两点：**

- **卸载不会删除这个文件夹** —— 你的设置和备份会留着，重装后还在。
- 想**彻底清干净**：卸载完之后手动删掉 `%LOCALAPPDATA%\WinTuneBox` 就行。
  （如果你开过「开机自动启动」，建议先在设置里关掉，或者在「启动项管理」里确认一下没有残留。）

| 权限模型 | `asInvoker`（只有需要时提权），不做高权限常驻 |
| 系统支持 | Windows 10 1607 及以上 / Windows 11（1607 以下由冻结的旧版覆盖） |
| 构建与签名 | MSBuild 打包 + Inno Setup 安装包 + Authenticode 代码签名，GitHub Actions 自动出包 |

想自己从源码编译、或者看目录结构和自检工具，见 [DEVELOPMENT.md](DEVELOPMENT.md)。
